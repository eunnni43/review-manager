나만의 GitHub 저장소 연결

GitHub에서 발급한 Fine-grained token을 이 기기에만 보관합니다. 이 사이트의 공개 코드에는 토큰을 넣지 않습니다. 휴대폰에서는 별도로 토큰을 입력해야 합니다.

GitHub Contents API에 reviews.json을 저장합니다. 변경 후 약 2초 뒤 자동 동기화를 시도하며 저장 결과가 상단에 표시됩니다. 서로 다른 기기에서 동시에 편집하면 충돌을 감지하고 자동 덮어쓰지 않습니다. GitHub API 사용 제한이 있으며 실시간 동시 편집용은 아닙니다.
